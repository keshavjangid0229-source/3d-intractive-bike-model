# 3D Sports Bike Showcase

An interactive sports bike viewer built with Three.js. Orbit and zoom around the model, switch between red, black and blue, or use the preset views to inspect the engine and front wheel.

[Open the demo](https://3d-intractive-bike-model.vercel.app/)

## Run locally

From the repository root, run `python -m http.server 8000` and open `http://localhost:8000`. The page loads Three.js over the internet and reads the bundled glTF model and textures.
